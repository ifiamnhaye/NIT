# Lab Summary

In this lab, I learned how to display the current date and time, check system uptime, and determine the current location in a Linux environment. I also practiced creating directories and files using commands such as `mkdir` and `touch`. Additionally, I learned how to navigate the file system using both absolute and relative paths.

## Difference Between Absolute and Relative Paths

The fundamental difference between an absolute path and a relative path comes down to their starting point:

- **Absolute Path:** Always starts from the root directory (`/`) and provides the complete, fixed location of a file or directory.
- **Relative Path:** Starts from the current working directory and specifies the location relative to where you are currently positioned in the file system.

## Most Useful Commands
